# AI Stock Radar — Visual Prototype

금융 사이트(Yahoo Finance/CNBC 계열)의 정보 밀도와 카드형 뉴스 UI를 참고해 만든 프론트엔드 프로토타입입니다. 실제 사이트의 디자인/상표를 복제하지 않고 시장 대시보드 구조만 참고했습니다.

## 포함 기능
- 반응형 금융 대시보드
- 시장 지수 티커
- AI TOP PICKS 순위/점수
- 시장 차트 SVG
- 뉴스 이미지 카드
- 실시간 뉴스 영역
- 테마/시장심리 태그
- 현재 시각 표시

## 실행
`frontend/index.html`을 브라우저에서 열면 바로 볼 수 있습니다.

## 실제 서비스로 발전시키기
1. KRX/미국 주가 API 연결
2. 금융뉴스 RSS/API 수집기 연결
3. 기업/종목명 엔티티 매칭
4. LLM 뉴스 요약·감성·영향도 분석
5. 재무/수급/거래량 지표 계산
6. 매시간 스코어 재계산 및 DB 저장
7. 로그인/관심종목/알림 추가
