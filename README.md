# AI Stock Radar v6

Vercel용 모바일 금융 대시보드입니다.

- 한국/미국 주요 주식
- AI TOP PICKS
- 종목 검색 및 상세 분석
- 시장 지표
- 한국뉴스 / 미국뉴스 / AI·반도체 / 금리·환율 / 기업뉴스 메뉴

## Vercel
`index.html`은 정적 페이지, `api/*.js`는 Vercel Node Functions로 배포됩니다.

투자 참고용 서비스이며 투자 조언이 아닙니다. 데이터는 지연되거나 오류가 있을 수 있습니다.
